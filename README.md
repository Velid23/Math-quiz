# Math-quiz
This project is an interactive Math Game application developed in C++, designed to challenge users with randomly generated arithmetic questions based on their chosen difficulty level and operation type. More than just a simple game, this project served as a comprehensive practical application of both fundamental and advanced programming concepts, including user input validation, control flow using switch cases and loops, the implementation of Enumerations (Enums) to handle game states, and the use of User-Defined Data Types (Structs) to pass data efficiently through functions by reference. The source file contains two distinct implementations of the game; the first is my own custom version which I built entirely from scratch using my own logic, while the second version (included at the bottom as commented code) is the instructor's implementation. Keeping both versions within this file documents my educational journey, as it allowed me to perform a direct comparison between our approaches. By analyzing the differences in code structure, logic flow, and data management, I was able to learn from my mistakes, identify areas for improvement, and significantly enhance my problem-solving and clean coding skills.
